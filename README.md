## 项目定位
本仓库用于系统化学习 C++，强调“理论 + 练习 +实践”的结合：
- **《C++ Primer》主线**：夯实语言基础与标准库使用能力。
- **数据结构与算法主线**：强化问题建模与复杂度意识。
- **应用实践主线**：将语法与算法能力迁移到实际开发场景。

## 如何使用本仓库
1. 从 `C++Primer/` 目录按章节顺序学习。
2. 结合代码逐步理解语法、标准库与常见编程模式。
3. 本地编译并运行示例后，再尝试独立复现与扩展。
4. 将同类题目或场景归纳成自己的知识清单，形成长期复盘材料。

## 学习目标
- 建立扎实、可迁移的 C++ 基础能力。
- 形成对常见数据结构与算法的系统认知。
- 提升从“语法会用”到“工程可用”的实践能力。

## 推荐学习路径
- **阶段 1：语言基础** —— 以《C++ Primer》章节学习为主，打牢语法与标准库基础。
- **阶段 2：算法训练** —— 在掌握基础后，聚焦数据结构、复杂度分析与题目训练。
- **阶段 3：应用实践** —— 结合小型项目或功能模块，训练代码组织与问题拆解能力。

## 编译与运行建议
- 建议使用支持现代 C++ 标准的编译器（如 `g++` / `clang++`）。
- 可先在对应章节目录内对单文件进行编译与运行，再逐步整理为自己的构建流程。
- 建议开启常用警告选项，及时发现潜在问题。
